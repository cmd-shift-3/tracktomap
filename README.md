# TrackToMap

Веб-приложение для наложения GPS-трека (GPX/TCX) на скан бумажной карты — например, карты ориентирования — с ручной привязкой по опорным точкам и раскраской маршрута по темпу.

Работает полностью в браузере, без бэкенда: обработка файлов, привязка и рендер — на canvas, состояние сохраняется локально (localStorage + IndexedDB), так что карта, трек и все настройки остаются на месте после перезагрузки страницы.

## Возможности

- **Загрузка карты и трека** — JPG/PNG для карты, GPX/TCX для трека; через кнопки в шапке, дропзону на пустом экране или drag-and-drop прямо на карту.
- **Привязка трека к карте по опорным точкам** — выбираете точку трека (по слайдеру или времени) и кликаете, где она находится на карте. Между соседними опорными точками строится независимое подобие (поворот + масштаб + сдвиг), поэтому добавление одной точки не сдвигает уже привязанные участки трека.
- **Отмена/повтор** (Ctrl/Cmd+Z, Ctrl/Cmd+Shift+Z или Ctrl/Cmd+Y) для всех действий с опорными точками.
- **Перестановка и ретайм опорных точек** — можно передвинуть точку по карте или изменить её время, не удаляя.
- **Обрезка трека** — отдельная модалка сразу после загрузки трека (и кнопка «Изменить обрезку» позже), чтобы убрать лишнее время до старта/после финиша. Обрезка влияет на статистику, отрисовку и точку отсчёта времени.
- **Раскраска маршрута по темпу** — линия трека красится в градиент (по умолчанию зелёный → жёлтый → оранжевый → красный) с настраиваемыми границами шкалы и цветами остановок.
- **Настройка линии** — прозрачность, толщина, толщина чёрной обводки.
- **Зум и панорамирование карты** — слайдер зума, Ctrl/Cmd + колесо мыши (зумит к точке под курсором), перетаскивание зажатой мышью, прокрутка на мобильных.
- **Статистика трека** — дистанция, время, средний темп (с учётом обрезки).
- **Тёмная/светлая тема** с анимированным переключением (View Transitions API с фолбэком для браузеров без поддержки).
- **Автосохранение состояния** — карта (в IndexedDB), трек и все настройки (в localStorage) восстанавливаются при следующем открытии страницы.
- **Экспорт** результата в PNG или JPEG (формат подбирается под формат исходной карты).
- **Адаптивная мобильная вёрстка** — отдельный layout для экранов до 800px.

## Как пользоваться

1. Загрузите карту (JPG/PNG) и трек (GPX/TCX).
2. В открывшейся модалке настройте обрезку начала/конца трека (или пропустите — можно вернуться к этому позже кнопкой «Изменить обрезку»).
3. В панели «Привязка» выберите точку трека (слайдером или вводом времени) и нажмите «Добавить опорную точку», затем кликните на карте, где эта точка находится в реальности. Повторите для 2+ точек — чем их больше и чем равномернее они расставлены вдоль трека, тем точнее привязка.
   - Быстрый способ: двойной клик прямо по треку на карте сразу выбирает точку и включает режим добавления.
4. Настройте внешний вид: цвета и границы шкалы темпа (панель «Темп»), прозрачность/толщину/обводку линии (панель «Линия»).
5. Нажмите «Сохранить», чтобы экспортировать готовое изображение.

## Структура проекта

```
index.html       — разметка страницы
css/style.css     — вся стилизация, включая тёмную тему и мобильный layout
js/geo.js         — плоская проекция lat/lon → метры, расстояние по гаверсинусу
js/transform.js   — подгонка преобразования "метры трека → пиксели карты" (similarity transform по опорным точкам)
js/gpx-parser.js  — разбор GPX и базового TCX в единый формат точек
js/track.js       — статистика трека (дистанция, темп, сглаживание), раскраска по темпу
js/app.js         — состояние приложения, отрисовка на canvas, обработка UI, сохранение/восстановление состояния
```

## Технические детали

- **Модель привязки**: посегментное подобие (rotation + scale + translation, без перекоса) между каждой парой соседних опорных точек, решается в замкнутой форме через комплексные числа. Трек проходит точно через каждую расставленную опорную точку.
- **Отрисовка линии**: двухпроходная техника на отдельном буферном canvas — сначала рисуется сплошная «форма» линии с `lineJoin: round` (без артефактов на резких разворотах), затем поверх неё в режиме `source-atop` наносится раскраска по темпу отдельными сегментами, обрезанная точно по контуру формы.
- **Хранение**: карта — Blob в IndexedDB; точки трека — отдельный ключ localStorage (перезаписывается только при загрузке нового файла трека); остальные настройки — debounced запись в localStorage, чтобы частые события (перетаскивание слайдера) не писали на диск на каждый кадр.
- **Retina-поддержка**: canvas рендерится с учётом `devicePixelRatio` для чёткости на экранах с высокой плотностью пикселей.
- Внешних зависимостей и сборки нет — чистые HTML/CSS/JS, достаточно открыть `index.html` в браузере (или раздать статикой).
